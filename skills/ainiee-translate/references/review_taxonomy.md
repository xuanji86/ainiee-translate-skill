# 审核缺陷分类（A–E）与 AI 味十二条清单

给 Reviewer / Challenger / Consistency auditor 读的标准。每条 finding 必须归入 A/B/C/D 之一；**E 不是发现类别，是禁区**：
触碰 E 的 finding 一律作废。例子以英→中为主，其他目标语言同理。项目自己的病例放 `<PROJ>/work/review/EXAMPLES.md`。

## A 误译 / 事实错（severity 3，偶有 2）

源文意思没译对，或漏了成分。**必须引用源文证据**（`source_evidence`）。常见病因：

| 病因 | 例 |
|---|---|
| 颜色/专有搭配当普通词 | `dusty rose`（暗玫瑰色）→「尘土般的玫瑰色」 |
| 习语直译 | `turned on her heel`（猛地转身）→「踮着脚转身」；`That makes two of us`（我也一样）→「那就有两个了」 |
| 反问/否定方向翻转 | `So?`（那又怎样）→「是吗？」；`He's going to die for this`（偿命）→「他要为此去死」 |
| 代词指向 | `I've got her`（her=船）→「找到她了」 |
| 比较结构断裂 | `I need you more than you need me` → 「我比你更需要你」 |
| `one of`、量的成分丢失 | `one of our ships` → 「我们一艘船」（丢「其中」） |
| 军衔/称谓整个漏掉 | `Gul Akellen Macet` → 「指挥官 Akellen Macet」 |
| 多义词取错义 | `override panel`（超控面板）→「越权面板」；`rule out`（排除可能）→「把故障排除掉」 |

## B 目标语硬伤（severity 3 或 2）

不看源文也能判定的错误：

| 类型 | 错 → 对 |
|---|---|
| 生造词 / 非词 | 刻人的目光→刺人；拍了主意→当机立断；耐心消减→耗尽；一头竖发→刺猬似的短发 |
| 固定词误用（真词取错义） | 落成一阵低响（落成＝竣工）→沉成；张力（物理）→紧绷；手工（工艺）→成果；弹道→轨迹 |
| 成语缺字 / 误用 | 有过之无不及→有过之而无不及；一死了之（逃避）≠ blaze of glory |
| 动词当名词 | 她的褫夺已被解除→对她的褫夺教籍已经解除 |
| 词序颠倒 / 搭配错 | 喉咽→咽喉；饥渴啄着他→啃噬着他；压过那股疲惫→压下 |
| 量词误用 | 一对小说→两部；每一面表面→每一处；那张倒影 |
| 缺成分 | 「他会冲下层堆芯的系统电容控制」（缺「向」） |

## C 翻译腔 / AI 味（severity 2 或 1）

目标语没错，但一眼看出是从源语硬搬过来的。逐句对照十二条：

| # | 症状 | 病例 → 处方 |
|---|---|---|
| 1 | **句式硬搬**：疑问/否定/强调/`long enough to`/`back to his feet` 按源语语序直译 | 那甚至怎么可能？→这怎么可能？；把自己推回到脚上站着→重新站起来；瞥的那一眼足够长，看清了→瞥了一眼，足够看清 |
| 2 | **同义叠用**：近义词叠在一起，或一件事说两遍 | 虔敬的敬畏→敬畏；事情的实情→实际情况；酸那股发酸的刺痛→酸液那股酸涩的刺痛 |
| 3 | **「的」堆叠**：≥3 层定语或「的的」相连 | 她曾是的那个女人的一个苍白仿本→只剩从前那个自己的苍白仿本 |
| 4 | **抽象名词化**：动作被名词化再加「的进行/的到来/对…的攥握」 | 观察扫描的进行→看着扫描进行；只有有限的成功→成效有限；愤怒对她心的攥握→心里那股愤怒 |
| 5 | **被/使/进行 滥用** | 被…所回应→主动句；让 X 被杀→害死 X；被撕在 A 与 B 之间→在 A 与 B 之间撕扯 |
| 6 | **句子重心移位**：源语主句被推到长状语之后，读来像补充说明 | 「…会合时，手里那把相位步枪压手」→「相位步枪在他手里沉甸甸的。他…会合」——主句先落地 |
| 7 | **生造词 / 非词**（与 B 类重合时按 B 报） | 空白广袤、承压嘶叫、赌法 |
| 8 | **固定词误用**（与 B 类重合时按 B 报） | 相等（数学）→一致；中立的神色→神色平淡 |
| 9 | **量词 / 编制词错位** | 作战单位用「队」、技术小组用「组」；一个声音→一种声音（有修饰语时） |
| 10 | **连接词缺失**：因果/条件靠读者脑补 | Kira 倒下，他便是→Kira 一倒下，他就是 |
| 11 | **语域错位**：军令拖泥带水；日常对白硬套书面语；叙述过度文艺 | 回报以领受新命令→立即报到，听候新命令；再无所许（生造文言） |
| 12 | **成语 / 习语**：缺字、直译、误用 | 同一主题的不同说法→变奏；那袋医学奇迹→医学锦囊；压到他头上（be on top of）→追上 |

**不算 C 类（别报）**：单纯用词偏好（说/道、随即/接着）；长句本身（重心不移位、定语不堆叠就可以）；源文本身冗余的并列；
源文刻意的短促节奏（三个单音节形容词并列）；作者的冷幽默或比喻（`experience`、`the past lashed out`）；已在项目红线里的写法。

## D 跨段不一致（severity 2）

单段看不出，要对照多段。Reviewer 只报**本组内**能看到的；跨组/全书级别由 Consistency auditor 拿 `inventory.json` 判：

- 漂移：同一英文术语两三种译法（`catwalk` 悬空走道/步道/天桥；`utility corridor` 勤务/维修通道）；作者刻意逐字重复的台词译得不一样。
- 合理变化（别报）：`the captain` 指不同人；动词/形容词形态变化；红线里注明的语境分工（`crew` 舰上「船员」/站上「站上人员」）。
- 统一方向：优先（1）红线/词汇表已定的；（2）出现次数最多的；（3）最准确的。**auditor 只看自己范围的计数，全书计数可能相反**——
  主控在过目表里要核一次全书（Warpath D-005 「后舱→尾舱」就是方向反了）。

## E 红线（禁区，不是 finding）

项目 `POLISH_REDLINES.md` / `config.json.redline` 里的全部写法：用户亲自裁定，**看起来不一致也是故意的**。典型：
并存的英文/中文译名、无空格的「Alpha象限」、军衔写法（上校 vs 舰长）、舰名带「号」、舰船代词「她」、
定稿的多义词取向（shroud→隐形）、地球典故人名的中文化。finding 的 `offending` 或 `proposed` 触碰任何一条 → 作废。
另：人名一律原文；`<i>/<b>` 数量与源文相等；对话引号按 STYLE_GUIDE（中文用 “ ”，内层 『 』，绝不用「」）。
